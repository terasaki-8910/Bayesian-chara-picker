## 台詞の決まり(本人と決めたもの・試作で使ったもの)

- 原作(アニメ・漫画・ゲーム・公式の媒体)で、そのキャラ本人が実際に言う台詞だけ。日本語版の言い回しのまま。言い換え・要約・「言いそうな台詞」は作らない。見つからなければ空のままでよい。
- そのキャラの性格や特徴が伝わるもの(口癖・決め台詞・自己紹介のボイスなど)。
- 長さは 40 字くらいまで、長くても 60 字。1 体に 0〜3 個。「」と改行は入れない(表示側で付ける)。
- 歌詞は使わない(著作権)。ボーカロイドのように台詞の無いキャラは空。
- VTuber は本人の定番の挨拶・口癖だけ。配信中の失言や揉め事に関わる発言は使わない。
- 性的・差別的な台詞は使わない。物語の大きなネタバレ(死・正体の明かし)は避ける。
- **年齢などを理由にキャラを外したり、台詞を外したりしない**(本人の強い指示。キャラの除外の決まりは R10 のとおり)。

## データの形(案)

`data/quotes.json`:

```json
{
  "version": 1,
  "characters": {
    "<キャラの id>": [
      { "text": "台詞", "source": ["根拠の URL"], "checked": "verified" }
    ]
  }
}
```

- `checked`: `verified`(Web で同じ言い回しを確かめた)/ `corrected`(言い回しを出どころに合わせて直した)。
  記憶だけで書いたものを入れるかは、下の「本人に決めてもらうこと」の 1。
- サイトへは、`text` だけを `public/chara-picker/quotes.json`(`{ version, generatedAt, characters: { id: [台詞] } }`)にして渡す。
  変換はサイトの同期スクリプトに足す(サイト側の作業。こちらで data/quotes.json ができたら、サイトのセッションに頼む)。
  それまではサイトが種の 79 個を自前で持つ。

## 進め方の案

1. **記憶で書く**(全 2002 体): 作品ごとにまとめてエージェントに分ける(作品の知識で思い出しやすい)。high / medium を付ける。
2. **medium を Web で確かめる**(Sonnet)。言い回しは出どころに合わせて直す。
3. **記憶で書けなかったキャラを Web で探す**(Sonnet)。
   - ソシャゲは攻略 wiki のボイス一覧(自己紹介・ガチャのボイス)。
   - アニメ・漫画はピクシブ百科事典・ニコニコ大百科の「名台詞」の節。
   - ピクシブ百科事典・atwiki・Fandom は WebFetch が 403/402/418 になることが多かった。検索結果の要約で確かめる。
   - Firecrawl はクレジット切れ(2026-10-29)。
4. おまかせで出やすい順(供給量「豊富」680 体 → 「十分」700 体 → 「少ない」408 体 → 「僅少」211 体)に進めると、
   少ない作業で多くの抽選に台詞が出る。「豊富」だけで抽選の約 48%、「十分」までで約 86%(main の 2002 体の時点)。
5. 決めたことは `docs/decisions.md` に。push とサイトへの同期は本人の返事を待つ。

## 費用の目安(試作の実測から)

- 記憶で書く: 1 体あたり約 1,300 トークン → 全体で約 260 万(Opus)。
- Web で確かめる: 1 個あたり約 6,300 トークン・検索 3 回ほど(Sonnet)。
- Web で探す: 1 体あたり、確かめるより多い(探して確かめるので、1 万トークン前後と見込む)。記憶で書けないキャラが 6 割なら、約 1,200 体分。
- 全部を Web で確かめて探すと、合わせて 2,000 万トークン前後になる見込み。数日に分けて進める大きさ。
